# 《巴士海峡封锁》战役设计契约

## 1. 战役意图

- **时限**：3,000 秒（50 分钟），处于 45–60 分钟目标区间。
- **红方任务**：075 编队从浅海西侧穿越浅深海交界，进入东侧撤离区；岸基反舰/防空单元迟滞蓝方。
- **蓝方任务**：America 编队从深水东侧进入西侧撤离区；以 F-35B/EA-18G 压制红方岸导并保护两栖核心。
- **共同约束**：两栖核心均有 `preserveCapability + withdraw` 必要目标；失能会导致关键失败，进入撤离区后仍需在终局核算保全能力。
- **不对称性**：红方拥有岸基 DF-21D、近岸电子支援和 039C；蓝方拥有 F-35B、EA-18G、P-8A、Virginia 和更强深水 ISR。

## 2. 编组与实际消费

|---|---|---|---|---|
| 红 | 两栖穿越群 | 075、054B、055 | 运-9G、歼-10C、运油-20U | 039C |
| 红 | 岸基拒止群 | DF-21D 岸导、远程 SAM | — | — |

所有平台均已有四层 Catalog 外键；机库只引用兼容挂载并使用真实 `ready/reserve/turnaroundSupply`。

## 3. 地理与环境

- 北部台湾南端和南部吕宋北端为不可穿越陆地区域，岸基单元必须落在陆地多边形内。
- `bashi_shallow_shelf`：西侧/海峡陆架，声呐距离因子 `0.72`，有利于低速 AIP 隐蔽。
- `bashi_deep_basin`：东侧深水区，声呐距离因子 `1.15`，有利于 Virginia/P-8A 搜索。
- 红方撤离区位于深水东缘；蓝方撤离区位于浅海西缘。两栖舰初始距各自撤离区约 6–8 km，20–22 kt 下约 8–12 分钟抵达；完成撤离后护航/岸基对抗继续至50分钟结算。

## 4. 任务与事件链

1. 护卫舰/驱逐舰执行 `escort`，以各自 LHD/LHA 为 `escortUnitId`。
2. 039C 与大鲸/Virginia 在浅深海交界执行 `asw_patrol`；P-8A加入蓝方深水搜索。
3. 开战 20 秒红蓝首次起飞轻型鱼雷反潜直升机；300 秒第二波；900 秒第三波通过可靠出动队列等待可用库存/Turnaround。
4. 开战 60 秒 America 放飞 F-35B 对海波次，1,200 秒放飞护航轮换；真实机库库存和甲板冷却均生效。
5. 只有在陆地辐射 Contact 达到 `classified` 后才激活相应 SEAD：歼-10C压制蓝方 PAC-3，EA-18G压制红方岸基拒止防空节点；非辐射岸舰发射车不能被ARM凭隐藏真值攻击。
6. 两栖舰进入撤离区时广播通报，实际完成状态由版本化 withdraw Objective 结算，不由事件奖励替代。

## 5. Objectives 与终局

| 阵营 | 必要目标 | 可选目标 |
|---|---|---|
| 红 | 075 保持任务能力；075 进入东侧撤离区 | 使 America/蓝方岸基节点失能；保全运-9G |
| 蓝 | America 保持任务能力；America 进入西侧撤离区 | 使 075/红方岸导失能；保全 MQ-4C |

- 任何必要 `preserveCapability` 失败可触发关键失败终局。
- 3,000 秒到时结算撤离、保全与可选积分；无命令路径也必须有限终局。
- 红方可行路径：保持 054B/055 防空，主动 EMCON，压制 PAC-3，075 直航东撤。
- 蓝方可行路径：EA-18G/F-35B压制岸导，星座/伯克分层防空，America 直航西撤。

## 6. 库存和平衡初值

- 两栖舰不增加场景专属无限库存；完全使用平台 Catalog 的有限 HQ-16FE/ESSM、HQ-10/RAM、反舰弹和机库批次。
- 首波反潜采用 prosecute 挂载以促成真实弹药消耗和返航；后续事件不得凭空创建航空兵。
- 岸导是高威胁但可被 ARM 压制；蓝方 F-35B 波次数量受 America 的 3 个总批次限制。
- 所有事件使用固定仿真时间、稳定 ID 和待执行订单；不使用墙钟或非序列化随机源。

## 7. 验证与回滚

- Schema 预校验：陆海空初始位置、任务阵营、escort 引用、机库槽/挂载、事件引用、撤离域和多边形全部在首 Tick 前检查。
- 固定种子：`7373`；摘要必须记录 Tick、结果、损失、弹耗、事件、出动、待执行订单和 AAR 数量。
- 关键路径测试通过受控状态分别完成红方东撤和蓝方西撤，不依赖隐藏真值。
- 回滚单位：单独移除 `SCENARIO_BASHI_CHANNEL_BLOCKADE` 与 BUILTIN 注册；Catalog 和引擎机制不依赖该想定，可独立保留。
